# Hotel Pawar - Restaurant Website

Hotel Pawar is a restaurant website created using HTML and CSS.

## Pages

* Home
* About
* Gallery
* Menu
* Contact
* Review

## Technologies Used

* HTML5
* CSS3

## Features

* Attractive restaurant homepage
* Navigation between multiple pages
* Restaurant menu with food items
* Food gallery
* About Hotel Pawar section
* Contact information
* Customer review section
* Custom CSS styling

## Website

Hotel Pawar is a restaurant website designed to provide information about the restaurant, its menu, gallery, contact details and customer reviews.
